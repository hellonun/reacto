# Reacto

Cardboard creations that come to life.

| Folder | What it is | Published? |
|---|---|---|
| [`phone/`](phone/) | Phone-powered creations: build something from cardboard, pop a phone in, and the phone brings it to life (Eyes, Engine). | Yes — [hellonun.github.io/reacto](https://hellonun.github.io/reacto/) |
| [`peekasaurus/`](peekasaurus/) | Arduino-powered cardboard dinosaur: a colour-sensing head, a shake-to-wiggle body and a tail that wiggles when you wave at it. | No — hardware code and wiring guides |

Only `phone/` is published to GitHub Pages, by the workflow in `.github/workflows/pages.yml`. Everything else stays in the repo but off the website.
